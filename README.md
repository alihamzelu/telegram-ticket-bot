# Telegram Support Ticket Bot

A simple and efficient Telegram bot for handling user support tickets. Users can create tickets, and admins can manage, respond, and track them through the bot.

---

## Features

- Create support tickets via Telegram
- Unique ticket system for each request
- Admin panel via bot commands
- Reply system between user and admin
- Ticket status tracking (open / closed / pending)
- Lightweight and fast

---

## Tech Stack

- Python
- python-telegram-bot
- MySQL
